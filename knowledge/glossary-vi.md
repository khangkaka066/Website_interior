# Thuật ngữ

| Thuật ngữ trong shop | Tiếng Anh | Nghĩa (theo nguồn) | Nguồn |
|---|---|---|---|
| **Rèm cầu vồng** | Zebra blinds / day-night blinds | Rèm cuốn vải sọc mờ xen sọc đặc, kéo dây để chỉnh ánh sáng. **Không phải màn sáo lá dọc.** | Catalog Cầu Vồng |
| **Rèm cuốn** | Roller blinds | Một tấm vải cuộn quanh ống, kéo xuống để che. Có dòng cản sáng 100% và dòng lọc sáng 50% | Catalog rèm cuốn |
| **Rèm ORE / rèm khoen** | Eyelet / grommet curtain | Rèm vải gấm may sẵn, gắn khoen đục lỗ để xỏ thanh treo | Mô tả `sp5449957048` |
| **Rèm dán tường** | | Rèm gắn bằng miếng dán (mặt gai/mặt bông) lên tường hoặc khung, không cần khoan thanh | `sp28830763252` (miếng dán) (?) |
| **Rèm móc RIDO** | | Rèm treo bằng móc, tên gọi theo sản phẩm của shop (?) | `sp28482500494`, `sp28882500901` |
| **Rèm voan / voan lụa** | Sheer curtain | Rèm mỏng lọc sáng, che mờ, dùng lớp trong của rèm hai lớp | Danh mục `voan-lua` |
| **Rèm hai lớp** | Double-layer curtain | Một lớp vải gấm chống nắng và một lớp voan | Các sản phẩm "2 lớp" |
| **Vải gấm** | | Vải trơn gấm pha poly bóng, dùng làm lớp chống nắng của rèm ORE/dán tường | Mô tả `sp5449957048` |
| **Chống nắng / cản sáng** | Light-blocking / blackout | Mức che sáng. Catalog VH BLINDS ghi % từng mẫu; mô tả Shopee ghi "95%" | Catalog; mô tả |
| **Độ nhún sóng** | Fullness | Hệ số tổng chiều ngang rèm so với chiều rộng cửa (x1,5 - x2,5) | `guides-from-listings.md` |
| **Lọt lòng** | Inside mount | Đo trong khung cửa | Mô tả rèm |
| **Thanh treo / thanh ray** | Curtain rod / track | Thanh nhôm treo rèm (có đủ pát, đầu chụp, cút); thanh ray trượt gắn trần | Danh mục `thanh-treo` |
| **Pát đỡ, đầu chụp, cút cột, khoen, bi trượt, dây vén màn** | Bracket, finial, joint, ring, runner, tieback | Phụ kiện rèm | Danh mục `thanh-treo` |
| **Hệ Grand / Prime** | | Hai kiểu hộp rèm của rèm cầu vồng: máng vuông to / máng vuông nhỏ | Catalog Cầu Vồng tr.5 |
| **Hệ Opaque / Standard** | | Hai kiểu máng của rèm cuốn: máng cản sáng / máng tiêu chuẩn | Catalog rèm cuốn |
| **Manual / Motorized** | | Kéo dây tay / điều khiển tự động | Catalog |
